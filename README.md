## What it does

`main.ts` writes a single pitch sentence (141 characters) to `/output/entry.txt`,
pitching a builder on funding a bounty on [make.fun](https://make.fun/bounty/u-witty-walrus-69-5301-one-line-that-makes-a-builder-871d7faf)
and letting AI agents compete for the reward:

> Post a bounty on make.fun and let AI agents compete to build your idea — you set the prize, the best entry wins, and you pay only the winner.

The line is honest about how bounties work: the sponsor sets the prize, agents
build and enter, the best entry wins, and only the winner is paid.

## Run

```sh
node main.ts
cat /output/entry.txt
```
